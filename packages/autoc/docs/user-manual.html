claude-autosar 用户手册

面向 AUTOSAR BSW 工程师的终端 AI 助手 — 用自然语言描述配置目标，AI 在工程里完成改参、依赖计算与校验。

核心能力

  • 双格式平级 IO — ARXML（AUTOSAR r4.0–4.8）+ XDM（EB DataModel2 2.0/1.0），dispatcher 按根 xmlns 自动路由，不互转
  • BSW 改参 — bsw_write 支持 reference chain 解析、type 启发式、surgical patch（byte-identity 100%）
  • BSW 校验 — bsw_verify 调用 EB tresos_cmd，结构化解析 6 类正则 + severity
  • Lint 引擎 — 38 条规则（29 ARXML + 9 XDM），按 namespace 自动过滤
  • 模板 diff + apply — current vs template 对比，支持 add/modify/delete，dry-run + apply 两阶段
  • 会话留痕 — JSONL append-only 改参日志 + 不可变树 + fork + 自包含 HTML 导出
  • MCP 集成 — Claude Code 子 Agent 直调 15 个工具，ISO 21434 信任边界

快速上手

场景 1：初始化 EB tresos 工程

# 进入 EB tresos 工程目录（含 .prefs/ 目录）
cd /path/to/tresos/project

# 交互式初始化
claude-autosar init

# 非交互式（CI / 脚本）
claude-autosar init --non-interactive \
  --tresos-home "C:/EB/tresos" \
  --mcal-vendor nxp \
  --chip "Mcu_s32k148_lqfp176.epd"

场景 2：查看模块配置

# 自动检测格式（ARXML / XDM），生成 HTML 报告
claude-autosar bsw-inspect Mcu_Cfg.arxml -o report.html

# 带 lint 检查
claude-autosar bsw-inspect Mcu_Cfg.arxml --lint -o report.html

场景 3：修改参数

# 通过 MCP 工具（Claude Code 内）
bsw_write(module="Mcu", params=[
  {"path": "Mcu/ClockConfiguration/McuClockSettingConfig_0/McuClockReferencePointFrequency", "value": "80000000"},
  {"path": "Mcu/SecConfig/SecurityAttributeConfig_0/McuSecRam", "value": "ENABLE"}
], project="/path/to/tresos/project")

# 通过 CLI（EB tresos）
claude-autosar eb save --project /path/to/tresos/project --module Mcu \
  --param "Mcu/ClockConfiguration/McuClockSettingConfig_0/McuClockReferencePointFrequency=80000000"

场景 4：模板 diff + apply

# dry-run：只看 diff 报告
claude-autosar arxml-apply-template current.arxml template.arxml -o diff.html

# apply：写入变更
claude-autosar arxml-apply-template current.arxml template.arxml --apply -o diff.html

场景 5：Lint 检查

# 对单个文件运行全部规则
claude-autosar lint Mcu_Cfg.arxml -o lint-report.html

# 只运行指定规则
claude-autosar lint Mcu_Cfg.arxml --rule COM-AP-001

# 按 severity 过滤
claude-autosar lint Mcu_Cfg.arxml --severity error

CLI 命令

claude-autosar init CLI

初始化 EB tresos 工程：生成 .autoc/autoc.yaml + .autoc/settings.json + 拷贝 BSWMD 模板。

参数

  • --project-root EB tresos 工程根目录（含 .prefs/）。默认：当前工作目录 可选
  • --tresos-home EB tresos 安装目录。默认：平台默认探测或交互询问 可选
  • --mcal-vendor MCAL 厂商：nxp / st / ti / renesas / infineon 可选
  • --mcal-vendor-home MCAL 厂商 AUTOSAR 包目录 可选
  • --chip 芯片衍生文件名（如 Mcu_s32k148_lqfp176.epd） 可选
  • --non-interactive 非交互模式，缺失参数用默认值。适合 CI / 脚本 可选
  • --no-bswmd 跳过 BSWMD 拷贝（只写 autoc.yaml） 可选
  • --refresh-bswmd 强制刷新 BSWMD（即使 mtime 未变） 可选

示例

# 交互式（推荐首次使用）
claude-autosar init

# CI 非交互
claude-autosar init --non-interactive \
  --tresos-home "C:/EB/tresos" \
  --mcal-vendor nxp \
  --chip "Mcu_s32k148_lqfp176.epd"

# 只更新 BSWMD
claude-autosar init --refresh-bswmd
claude-autosar eb CLI

EB tresos 工具适配器 — 通过 tresos_cmd 执行 save / verify / autocalc。

子命令

子命令功能说明
save保存参数到工程调用 tresos_cmd save
verify校验工程配置调用 tresos_cmd verify，结构化解析输出
autocalc自动计算依赖参数调用 tresos_cmd autocalc

参数

  • --project BSW 工程根目录 必填
  • --module BSW 模块名（如 Mcu、Port、Dio） 必填
  • --param 参数路径=值（可多次指定）。类型自动推断：true/false→BOOLEAN，整数→INTEGER，浮点→FLOAT，其他→STRING 可选（save）
  • --tresos-home EB tresos 安装目录 可选
  • --chip-derivative 芯片衍生文件名 可选
  • --mcal-vendor MCAL 厂商 可选

示例

# 修改 Mcu 模块的时钟频率
claude-autosar eb save --project /path/to/project --module Mcu \
  --param "Mcu/ClockConfiguration/McuClockSettingConfig_0/McuClockReferencePointFrequency=80000000"

# 校验工程
claude-autosar eb verify --project /path/to/project --module Mcu

# 自动计算依赖
claude-autosar eb autocalc --project /path/to/project --module Mcu
类型推断：--param 的值会自动推断类型。true/false→BOOLEAN，纯数字→INTEGER，含小数点→FLOAT，其他→STRING。无需手动指定类型。

claude-autosar lint CLI v0.4.0

对 .arxml / .xdm 文件运行 lint 规则检查。自动检测格式，按 namespace 过滤适用规则。

参数

  • path 待检查文件路径 必填
  • -o, --output HTML 报告输出路径（默认：不写文件，只输出 JSON 到 stdout） 可选
  • --rule RULE_ID 只运行指定规则（可多次指定） 可选
  • --severity 按 severity 过滤：error / warning / info 可选
  • --project 工程根目录（默认：cwd） 可选

示例

# 运行全部规则，输出 JSON
claude-autosar lint Mcu_Cfg.arxml

# 生成 HTML 报告
claude-autosar lint Mcu_Cfg.arxml -o lint-report.html

# 只检查特定规则
claude-autosar lint Mcu_Cfg.arxml --rule COM-AP-001 --rule NM-AP-002

# 按 severity 过滤
claude-autosar lint Mcu_Cfg.arxml --severity error

claude-autosar bsw-inspect CLI v0.4.0

通用 inspect 入口 — 自动检测 namespace 选择 ARXML / XDM 渲染器，生成单页式 HTML 报告。

参数

  • path 待检查文件路径（自动检测格式） 必填
  • -o, --output HTML 报告路径（默认：<input>.report.html） 可选
  • --lint 启用 lint 检查（在报告中嵌入 lint 结果） 可选

示例

claude-autosar bsw-inspect Mcu_Cfg.arxml

# XDM 文件

# 带 lint
claude-autosar bsw-inspect Mcu_Cfg.arxml --lint -o report.html

claude-autosar arxml-apply-template CLI v0.4.0

ARXML 模板 diff + apply — 对比 current vs template，生成 add/modify/delete diff 报告。

参数

  • path当前 .arxml 文件路径必填
  • template模板 .arxml 文件路径必填
  • -o, --outputHTML diff 报告路径可选
  • --apply执行写入（默认 dry-run，只生成 diff 报告）可选
  • --project工程根目录（用于 R6 路径解析）可选
# dry-run：只看 diff
claude-autosar arxml-apply-template current.arxml template.arxml -o diff.html

# apply：写入变更
claude-autosar arxml-apply-template current.arxml template.arxml --apply -o diff.html
注意：默认是 dry-run 模式，不会修改文件。需要加 --apply 才会实际写入。建议先 dry-run 确认 diff，再 apply。

MCP 工具

claude-autosar 提供 15 个 MCP 工具，供 Claude Code 子 Agent 直接调用。所有工具通过 stdio 协议通信。

MCP 启动方式：在 Claude Code 中配置 claude-autosar 插件，工具自动注册。也可手动启动：python -m claude_autosar.cli.mcp_server
bsw_read / bsw_write MCP

bsw_read — 读取模块参数

读取指定 BSW 模块的参数值。自动检测 ARXML / XDM 格式。

  • module模块名（如 Mcu）必填
  • path参数路径（如 Mcu/ClockConfiguration/...）必填
  • project工程根目录可选（默认 "."）

返回值类型自动推断：INTEGER / FLOAT / BOOLEAN / STRING。

bsw_write — 写入模块参数

批量写入参数值。使用 surgical patch 保持 byte-identity。

  • module模块名必填
  • params参数列表 [{"path": "...", "value": "..."}]必填
  • project工程根目录可选
// Claude Code 内调用示例
bsw_read(module="Mcu", path="Mcu/ClockConfiguration/McuClockSettingConfig_0/McuClockReferencePointFrequency")

bsw_write(module="Mcu", params=[
  {"path": "Mcu/ClockConfiguration/.../McuClockReferencePointFrequency", "value": "80000000"}
])
bsw_verify / bsw_autocalc MCP

bsw_verify — 校验模块配置

调用 EB tresos_cmd verify，返回结构化报告（severity + message + location）。

  • module模块名必填
  • project工程根目录可选
  • tresos_homeEB tresos 安装目录可选
  • chip_derivative芯片衍生文件名可选

bsw_autocalc — 自动计算依赖

调用 EB tresos_cmd autocalc，自动计算并写入依赖参数。

参数与 bsw_verify 相同。

bsw_verify(module="Mcu", project="/path/to/project")
bsw_autocalc(module="Mcu", project="/path/to/project")

数据模型

不可变 dataclass

所有数据模型使用 frozen=True，修改时通过 with_X() 返回新实例：

from claude_autosar.core.bsw.config import BSWModule, BSWParam, ParamValue, ParamType

# 创建参数
param = BSWParam(
    path="Mcu/ClockConfiguration/McuClockSettingConfig_0/McuClockReferencePointFrequency",
    value=ParamValue(raw="80000000", type=ParamType.INTEGER)
)

# 修改参数（返回新实例）
new_param = param.with_value(ParamValue(raw="160000000", type=ParamType.INTEGER))

ParamType 枚举

值说明
INTEGER整数
FLOAT浮点数
STRING字符串
BOOLEAN布尔值（true/false）
ENUMERATION枚举值
FUNCTION_NAME函数名（AUTOSAR 回调）

安全机制

XXE 防护

所有 XML 解析使用 _safe_parse()，显式禁用外部实体：

parser = etree.XMLParser(
    resolve_entities=False,  # 禁用实体解析
    no_network=True,         # 禁止网络访问
    dtd_validation=False,    # 不验证 DTD
    load_dtd=False           # 不加载 DTD
)

路径防御

MCP 工具的 project 参数限制在 _ALLOWED_PROJECT_ROOTS（cwd）内，防止路径遍历攻击。

输入校验

  • module 参数：正则白名单 ^[A-Za-z][A-Za-z0-9_]*$
  • path 参数：拒绝 .. 路径遍历
  • XPath 查询：参数化，防止注入

依赖安全

所有依赖版本 pin 上下界，防止供应链攻击。
