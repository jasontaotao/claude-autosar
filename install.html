1. 项目概览

claude-autosar 是 autoc-tool.com 的 Python 复刻版，外加 Claude Code 插件外壳。 仓库采用 monorepo：Python 核心 + Claude Code 插件。v0.3.0（Sprint 9.5 集成）交付 M1-T / M3 / M4 三大模块，已发布到 PyPI。

  • M1-T 双格式模板 diff + apply：.arxml 和 .xdm 模板对比与回写
  • M3 verify 增强：EB tresos verify 输出的结构化解析（6 类正则 + 严重度）
  • M4 lint 10 规则：8 条 arxml 规则 + 2 条 xdm 规则，applies_to 命名空间过滤

常用示例

7. MCP 工具

CLI 内置 FastMCP stdio server（python -m claude_autosar.cli.mcp_server），Claude Code 通过 .mcp.json 自动注册为工具。

工具列表

bsw_read

读取 BSW 配置（自动检测 arxml / xdm），返回模块树 + key params。

bsw_write

写 BSW 参数，preserve_format=True 保留字节级格式。

bsw_verify

EB tresos verify 结构化结果（severity 排序 + module 推断）。

bsw_autocalc

触发 EB autocalc，刷新派生参数。

arxml_validate

ARXML schema 校验 + IPdu / Signal / E2E 提取。

arxml_apply_template

ARXML 模板 diff + apply，--dry-run / --apply。

xdm_inspect

XDM 容器 / 叶子节点提取 + lint section。

xdm_apply_template

XDM 模板 diff + apply，preserve_format=True。

dbc_parse

DBC 解析（cantools），返回 message / signal 列表。

lint

10 条规则，--rule / --severity 过滤。

session_list / show / export

Session 元数据查询 + 导出。

log_export

10. 10 条 Lint 规则

v0.3.0 内置 10 条 lint 规则，每条带 applies_to 标签（arxml / xdm / both），自动按文件类型过滤。 数据缺字段时 skip 返回 0 violation（不误报优先）。

ARXML 规则（8 条）

COM-AP-001ComSignal > 8 byte 在经典 CAN 失败（CAN FD 才允许）arxml
COM-AP-002E2E Profile 缺失或未引用有效 ProfileConfigarxml
CanIf-AP-007软件全开 + 硬件全关：可能导致 CPU 风暴arxml
CanIf-AP-008CAN-FD length mismatch（PDU length vs DLC）arxml
ECUM-AP-001EcuM RunRequest 死锁：循环引用未释放arxml
ECUM-AP-003POSTBUILD variant 缺失（生产配置无 variant）arxml
GEN-AP-002BswM 自循环 action / rule（A 触发 A）arxml
NM-AP-001CanNm 报文未在 ComM 引用（孤儿 NmPdu）arxml

XDM 规则（2 条）

DEM-AP-001DemEventMemoryEntry 的 StorageAddress 越出 Flash 范围xdm
DEM-AP-004DemFreezeFrameFreezeFrameClassMaxLength > 255 byte 触发 UDS 限制xdm

运行 lint

# 单文件
claude-autosar lint .\tresos_home\Com\Com_Com.arxml

# 整个工程 + HTML 报告
claude-autosar lint .\tresos_home\ --html .\lint_report.html

# 按规则过滤
claude-autosar lint .\tresos_home\ --rule COM-AP-001

# 按严重度过滤
claude-autosar lint .\tresos_home\ --severity ERROR

# MCP 调用
> 用 lint 工具扫 ./tresos_home，规则 COM-AP-001, COM-AP-002

13. 排错指南

13.1 claude-autosar 不在 PATH

症状：'claude-autosar' 不是内部或外部命令 / plugin 报 未跑 verify：claude-autosar CLI 不在 PATH

# A 路径：从 PyPI 装（推荐）
pip install claude-autosar==0.3.0
claude-autosar --version    # → claude-autosar 0.3.0

# B 路径：从本地源码装
pip install -e D:\claude_proj2\autoc-cc\packages\autoc[dev]
where claude-autosar        # Windows

13.2 加载插件失败 — marketplace.json not found

检查 packages\plugin\.claude-plugin\marketplace.json 存在；如缺失需从 git 拉取。

13.3 MCP server 启动失败 — No module named 'claude_autosar.cli.mcp_server'

# 1) 装包
pip install -e packages\autoc[dev]

# 2) 检查 .mcp.json 中 env.PYTHONPATH 指向
#    D:/claude_proj2/autoc-cc/packages/autoc/src

# 3) 单独跑确认 stdio server 起来
python -m claude_autosar.cli.mcp_server

13.4 ARXML guard 误拒合法文件

症状：ARXML guard: ARXML schema invalid: ...（实际文件合法）

可能原因：namespace prefix 非 ar:、含 <?xml-stylesheet ?> 处理指令、lxml 解析严于浏览器。

绕过：改用 Edit 工具（matcher 包含但 path 解析不同）；或升级 guard packages\plugin\plugins\claude-autosar\hooks\pretooluse_arxml_guard.py。

13.5 lint 规则报 AttributeError

这是 9.5 集成修复前的旧 bug — 当前版本已加 applies_to tag + rules_for_namespace helper， 8 条 arxml 规则在 XDM 路径下自动 skip。如果仍遇到，确认版本为 v0.3.0：

claude-autosar --version    # 必须 ≥ 0.3.0
pip show claude-autosar     # Name / Version / Location

13.6 端到端 verify 返回 returncode != 0

tresos_cmd 不在 PATH / 缺 license / chip-derivative 拼错。提供完整 v2 路径即可：

claude-autosar bsw-verify \
  --chip-derivative S32K148 \
  --mcal-vendor NXP \
  --mcal-vendor-home "C:\NXP\SW32K1_S32M1xx_R21-11_4.0.0\eMcem" \
  --tresos-home "C:\EB\tresos"
