## 关键设计

1. **`BSWWritePathError` 是 frozen dataclass + Exception 派生**：
   - `__post_init__` 调 `Exception.__init__(self, self._format_message())`
   - `__str__` 输出 `<path>: <reason> [expected_min=X, expected_max=Y, actual=Z]` 单行可 grep
2. **`validate_writes_against_bswmd` 三段式**：
   - `registry is None` → 立即 return（向后兼容 9 个老 test）
   - 容器 multiplicity 校验：按父容器分组 + `existing + writes` 总量 vs `upper` / `lower`
   - 单 param 校验：type → range / enum_symbol
3. **路径语义**（plan R7）：ECUC 路径 `Mcu/Cfg_0/Freq` → DEFINITION-REF `/AUTOSAR/Mcu/Cfg/Freq`（去实例下标 + 前导根包名）。
4. **`modify_and_verify` 集成**：
   - 加 `bswmd_registry: BSWMDRegistry | None = None` 末尾 kwarg
   - 校验在 snapshot 之前；失败走 `ModifyResult(error=...)`，**不**抛 `ValidatorError`（9 个老 test 不破）
   - 校验失败不调 verify / save；文件不被改
5. **`BSWParam.def_ref`**：可选 None；构造器签名兼容（默认值 + `__post_init__` 类型校验）
