## CLI 集成细节

**eb.py 改动**（`cli/commands/eb.py:_run_save`）：
- `try: modify_and_verify(...) except Exception as e:` 捕获
- 调 `_maybe_typo_suggestion(e, ctx, args.module)`：
  1. 找 `<module>.xdm` / `<module>.arxml`
  2. 调 `load_module(target_file, module)` 拿 doc
  3. 用 regex 提异常 msg 里的 path
  4. 调 `BSWPathResolver.suggest_for_ecuc_set_value_error(err_path, doc)` 拿候选
- 非空时：
  - `payload["suggestions"] = list(suggestions)`（JSON）
  - `print(f"Did you mean: {s0}?", file=sys.stderr)`（人类可读）
- 空时：不显示 suggestion，错误信息原样

**davinci.py 改动**：与 eb.py 同样的 3 个 helper（`_maybe_typo_suggestion` / `_extract_err_path` / `_emit_did_you_mean`）—— CLI 集成是同模式，复制即可（避免引入额外共享模块）

**异常 msg 解析模式**（`_extract_err_path` 3 个 regex）：
```python
patterns = (
    r"path\s+'([^']+)'",        # "path 'X'" — validator._update_tree_value
    r"Path\s+'([^']+)'",        # "Path 'X'" — ecuc.set_value
    r"\"([^\"]+)\"\s+not\s+in", # "X not in ..." — fallback
)
```

## 关键决策

1. **CLI 错误捕获走 `try/except Exception`**：契约 4 + 7 没规定捕获范围；为了"传错 path 时给 suggestion"必须捕到 `modify_and_verify` 抛的所有异常（`ValidatorError` / `ValueError` / 任何子类型）。`Exception` 而非 `ValueError`：因为 `validator.modify_and_verify` 包成 `ValidatorError` 抛出，但 `__cause__` 是 `ValueError` —— 直接捕 `ValueError` 抓不到。
2. **`_extract_err_path` 用 regex 而非 import private**：契约段 4 没要求深耦合 `ecuc.py`；用 regex 提异常 msg 里的 path 字段简单且解耦（即使将来 `ecuc_set_value` 改 msg 格式也只影响 regex）。
3. **`suggest_for_ecuc_set_value_error` 的 `doc: ECUCDocument` 用 TYPE_CHECKING 块 import**：`ecuc.py` 和 `path_resolver.py` 在同一包；TYPE_CHECKING import 避免运行时 import（lxml 不需要被 path_resolver 直接依赖 —— `ecuc.ECUCDocument` 是纯 dataclass），也避免循环。
4. **davinci.py 复制 3 个 helper 而非抽公共模块**：plan 任务细节列 2 个文件都改；helper 总共 30 行，复制比抽公共模块更直观（避免在 sprint 8.E 中途创建 `cli/_typo_suggest.py` 之类新文件触发 code review 二次迭代）。后续 sprint 如有第 3 个 CLI 命令需要 typo 防御可重构。
5. **没改 `ecuc.py` / `validator.py` / `arxml_io.py` / `bswmd.py` / `conftest.py`**：严格遵守任务禁止项；`ecuc_set_value` 抛 `ValueError` 形态不变（`"Path 'X' not in ECUCDocument ..."`），`validator._update_tree_value` 抛 `ValueError` 形态不变（`"Path 'X' not found in tree ..."`），regex 覆盖两种。
6. **没改 `ecuc_set_value` 签名**：plan 明确"改签名会破 7 个老测试"；resolver 是 add-on 模式（契约 4 / D6 决定）。
