## 实现要点 (surgical patch 主路径)

1. 检测 path 后缀: `.tmp` (atomic 写中间产物) → 用 `path.with_suffix("")` 拿 ORIGINAL 路径做 patch, 然后写 patched bytes 到 .tmp.
2. 读 original bytes → 在原始字节 (字符串视图) 中 regex 找 `<VALUE>...</VALUE>` 段位置.
3. 用手写 walk 收集 tree 中所有 `<VALUE>` 元素当前文本 (规避 lxml 5+ `iter("{*}VALUE")` 在 comments / PIs 旁静默返回 0 的坑).
4. 数量对不上 → 抛 `_SurgicalPatchUnavailable` → 退路.
5. 无变化 → 直接返回原字节.
6. 有变化 → 倒序替换 (避免前面替换影响后面位置), 返回 patched bytes.
7. 退路: `etree.cleanup_namespaces + etree.tostring(..., doctype=tree.docinfo.doctype)` 保留 DOCTYPE + prefix.
