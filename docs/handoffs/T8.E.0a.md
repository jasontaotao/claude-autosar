## 关键实现细节

### ProjectConfig.load() 三层合并顺序（D13 决定 cwd 驱动）

```
1. <cwd>/.autoc/autoc.yaml            # 工程本地（最高优先）
2. ~/.autoc/agent/autoc.yaml           # 用户级
3. 平台默认 tresos_home 探测            # 兜底（Win: C:\Program Files (x86)\FlexCFG）
```

全部缺失 → 抛 `ProjectConfigError("未找到 autoc.yaml ...")`（D12 决定强制）。

### 极简 YAML 解析器（无 PyYAML 依赖）

- 仅支持契约 6 字段（str / null / list[str]）
- 文件不存在或解析错误 → 返回 `{}`（容错；不阻塞 init）
- 顶层不是 dict → 返回 `{}`
- 单/双引号字符串解引号 + 双引号反斜杠转义
- 行尾 `#` 注释自动忽略（保留引号内 `#`）
- YAML 字段顺序保留，extra_bswmd_paths 列表项去重 / 顺序稳定

### `autoc init` 交互流程

1. 问工程根目录（Rich `Prompt.ask` 循环重试直到目录存在）
2. 问 tresos_home（回车 = 平台默认）
3. 问是否复制 BSWMD 模板（Y/n）
4. 写 `<project_root>/.autoc/autoc.yaml`（契约 6 schema）
5. 复制 BSWMD（如选 Y）：遍历 `<tresos_home>/BSWMD/**/*_Bswmd.arxml` → `<project_root>/.autoc/bswmd/r22/<module>/`
   - mtime 未变 → 跳过（节省 IO）
   - `--refresh-bswmd` 强制重 copy
   - 用 `concurrent.futures.ThreadPoolExecutor(max_workers=4)` 并行加速
6. 工程验证：扫 `<project_root>/.prefs/` 下的 `*.xdm` / `*.arxml`，打印模块列表

### init 命令 flags

- `--project-root PATH` — 跳过工程根目录交互
- `--tresos-home PATH` — 跳过 tresos_home 交互
- `--non-interactive` — 缺字段即报错（CI / 脚本友好）
- `--no-bswmd` — 跳过 BSWMD 复制
- `--refresh-bswmd` — 强制重 copy BSWMD

## 边界处理

- `project_root` 不存在 → Rich Prompt.ask 循环重试到合法
- `tresos_home` 不存在 → 警告 + 降级（仍能用 `.prefs/` 值文件；跳过 BSWMD 复制）
- `<tresos_home>/BSWMD` 不存在 → 跳过复制 + stderr 警告
- `extra_bswmd_paths` 元素非字符串 → `ProjectConfigError` 明确指出字段
