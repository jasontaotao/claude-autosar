## 关键决策

1. **D1 决定落地**：`DEFAULT_NAMESPACES` 保留为 `WELL_KNOWN_NAMESPACE_URIS` 的 `is` 别名，**不**深拷贝 —— 老代码 `DEFAULT_NAMESPACES["ar"]` 取默认 URI 不破。
2. **detect_namespaces cache 选 mtime_ns 而非 mtime**：lxml 文件改写 mtime 可能精度丢，用 `st_mtime_ns`（纳秒）保证 cache 一定能区分。
3. **build_default_nsmap 重复 None 行为**：lxml 的 `root.nsmap` key 为 `None` 时 → 默认 ns，**始终**用 `'ar'` 作 key（D1 / contract 3 一致性）。
4. **ecuc.set_value nsmap kw 保留为扩展点**：T8.E.3 写 multiplicity / range 校验时需要 nsmap；本任务先加 kw 不实现（`# noqa: ARG001` 标记）。
