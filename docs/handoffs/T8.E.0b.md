## 关键实现细节

### 4 级优先级扫描（plan T8.E.0b / D14）

```python
candidate_roots: list[Path] = [
    project_config.bswmd_root,                                    # 1. 工程本地 r22 副本
    project_config.project_root / ".prefs",                       # 2. 工程 .prefs 副本
    *project_config.extra_bswmd_paths,                            # 3. 三方 CDD
    project_config.tresos_home / "BSWMD/AUTOSAR_R22/EcucDefs"     # 4. tresos_home 兜底
]
```

每级 root 用 `rglob("*.arxml")` 扫；解析失败的单个文件 → `logger.warning(...)` + 跳过（不阻塞其他文件）。

### 多源合并（D11：后加载覆盖前加载）

`BSWMDRegistry.merge(other)` 返回新实例，**不**改原对象：
- 同 `short_name` module → `other.modules[k]` 覆盖 `self.modules[k]`
- 不同 `short_name` → 两边都保留
- `source_paths` → 元组拼接
- `root_package_name` → `other` 优先（如果 `other` 有 modules）

### 根 `<AR-PACKAGE>` SHORT-NAME 探测（D11 决定）

不硬编码 `AUTOSAR`；扫整个文件第一个非空 `AR-PACKAGE/SHORT-NAME`。后续 Sprint（Agent F）可改成"按 namespace 推断"。

### frozen dataclass 的取舍

容器字段（`ContainerDef.param_defs` / `sub_container_defs` / `ModuleDef.containers` / `params` / `BSWMDRegistry.modules` / `source_paths`）用 `field(default_factory=...)` 初始化；merge 时 `dict(self.modules)` 拷一份再 `update`，**不**就地改 self。

- DEBUG：跳过不存在的 root / 0 arxml 的 root
- WARNING：单文件 parse 失败
